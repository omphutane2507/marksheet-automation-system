REST API Endpoints — for Power BI Web Connector and external tools

ℹ️
You must be logged in in the browser to access the API. Log in at http://127.0.0.1:8000/login/ first, then open these URLs.
💡
All endpoints support filter params: ?class_id=1  •  ?academic_year=2024-25  •  ?class_name=Std+III&division=A
API GEThttp://127.0.0.1:8000/api/marks/flat/
📊 Flat Marks — Primary Power BI Fact Table
The primary endpoint for Power BI. Returns every mark as one flat row containing academic year, class name, division, student name, roll number, subject name, marks obtained, absent status, percentage, and grade. This is your fact table — connect all other tables to this one.
One row per student x subjectGrade and % calculated~5,760 rows totalBest for Power BI
Filter ParamExampleEffect
?class_id=?class_id=1Only marks for classroom ID 1
?academic_year=?academic_year=2024-25Filter by year name
?class_name=?class_name=Std+IIIFilter by class name
?division=?division=AFilter by division
Open ↗
API GEThttp://127.0.0.1:8000/api/marks/students/
👤 Student Summary — One Row Per Student
Returns consolidated results per student: total marks obtained, total out-of, overall percentage, overall grade (A-E), pass/fail status, present count, absent count. Use in Power BI for KPI cards, toppers tables, and student drill-through reports.
One row per studentOverall % and gradePass/Fail flagAbsent count
Open ↗
API GEThttp://127.0.0.1:8000/api/marks/subjects/
📚 Subject Analysis — One Row Per Subject
Returns subject-level statistics per class: average marks, average percentage, pass percentage, and grade counts (A, B, C, D, E, AB). Use in Power BI for subject comparison bar charts, grade distribution heatmaps, and identifying weak subjects.

Connect Power BI — follow these steps when ready

1

Install PostgreSQL ODBC Driver

Download Npgsql from github.com/npgsql/npgsql/releases. Get the .msi file and install it. Then restart Power BI Desktop.

2

Get Data → PostgreSQL database

Open Power BI Desktop → click Get Data → search PostgreSQL database → Connect.

Server: localhost Database: school_marks_db Mode: Import (or DirectQuery for live data)
3

Enter Credentials

Username: school_marks_user Password: Om@1311
4

Select Tables in Navigator

marks_mark (fact table - load this first) marks_student (student dimension) marks_classroom (class dimension) marks_academicyear (year dimension - for slicers) marks_subject (subject dimension) marks_graderule (grade thresholds)
5

Set Relationships in Model View

marks_mark.student_id --> marks_student.id marks_mark.subject_id --> marks_subject.id marks_student.classroom_id --> marks_classroom.id marks_classroom.academic_year_id --> marks_academicyear.id
6

Build Your Dashboards

Bar Chart : Subject name vs AVG(marks_obtained) Pie Chart : Grade distribution (A/B/C/D/E counts) Table : Student name + total % + grade + pass/fail Card : Class pass rate % Slicer : academic_year[name] and classroom[class_name] Line Chart : Subject avg trend across 3 years
